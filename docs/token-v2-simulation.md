# Token v2 resource simulation

Generated by `npm run simulate:token-v2`. Deterministic reference-model results only; no chain calls.

One action costs one full unit. Each used unit recharges one internal tick/block, up to 144,000 ticks. A modeled day is 28,800 blocks. Real elapsed time is approximate.

## Shared activity and voting

100 paid units, no free allowance: 40 actions leave 60 available vote weight. Consuming that weight leaves 0 actions and 0 transferable tokens. After one modeled day, 20 action credits recover; they can instead fund the same amount of voting weight.

## Interpretation and limits

- Keep 100 free units as the comparison baseline; no allowance reduction is selected by this report.
- 25 or 50 free units visibly constrain ordinary 20-action/day traffic. Action pricing and target user journeys must be decided before reducing the allowance.
- These results measure resource accounting, not independent users, sustainable sponsor funding, transaction RC, reward fairness, capital concentration, or advertising effectiveness.
- Fully used tokens remain nontransferable until individually full, even when their recovered fractions add up to spendable actions.
- Cohort counts in these traces are not a worst-case on-chain bound. Storage growth, execution bounds and adversarial histories remain contract-port gates.
